# 计算概论 · 训练场

仿 LeetCode 的本地刷题网站，**单机、免注册**：打开就能刷。

- **代码就存在 `题库\练习\S1 ~ S9\` 里** —— 和 VS Code 打开的是同一份 `.cpp`
- **进度写回 `题库\进度追踪表.csv`**（每次写之前自动备份到 `训练网站\备份\`，保留最近 5 份）
- 判题支持 **C++ 17** 和 **Python 3**，两种语言分开存
- 只监听 `127.0.0.1`，局域网里的其他人连不上（也就没有账号、排行榜这些）
- 零依赖：只用 Python 标准库 + 系统里的 `g++` / `python3`，不用 pip、不用联网

---

## 一、启动

**双击 `训练网站\启动网站.cmd`**（文件内容是纯 ASCII，别往里加中文注释）。

浏览器会自动打开 `http://127.0.0.1:8756/`；端口被占用会自动往后找 8757、8758…
关掉那个黑窗口就停服务。

没装在默认位置的 Python，把 `启动网站.cmd` 里 `set "PY=..."` 那行改成自己的路径即可。

## 二、界面

```
┌──────────┬──────────────────┬────────────────────────┐
│ 题目列表  │ 题面              │ 代码编辑器              │
│ 250 题    │ 题目/输入/输出     │ 语言 ▾ C++ 17 / Python3 │
│ S1~S9     │ 示例 1、示例 2…    │ [运行][提交]            │
│ 搜索/筛选 │ 提示 + 样例说明    │ 测试用例/结果/提交记录   │
└──────────┴──────────────────┴────────────────────────┘
```

| 按钮 / 快捷键 | 作用 |
|---|---|
| `Ctrl+Enter` | 运行 |
| `Ctrl+Shift+Enter` | 提交 |
| 运行 ▶ | 跑「自定义输入」里的数据，**不判分** |
| ☑ 同时跑参考解并对比 | 你的输出 vs 官方参考解**逐行比对** —— 等于一个对拍器 |
| 提交 | 按官方样例判分，全过就在 `进度追踪表.csv` 里记「已通过」 |
| 参考解 | 看原始题库里的标准答案（没通过的会先拦一下） |
| ↻ 重读 / 重置 | 重新从磁盘读 / 恢复空白骨架 |

代码在停止输入 0.9 秒后自动保存到 `练习\`。所以随时可以用 VS Code 打开同一个文件接着写。

## 三、判题规则

| 语言 | 命令 | 时限 |
|---|---|---|
| C++ 17 | `g++ -std=c++17 -O2 -Wall -Wl,--stack=16777216` | 编译 60s / 运行 5s |
| Python 3 | `python -X utf8 main.py` | 运行 5s |

- 栈加到 16 MB（不然 S6 的深递归题会莫名崩）
- 比对忽略行尾空格、末尾空行、CRLF
  **例外**：`重排空格`（S3-065 / S9-181）要求输出长度与原串相同，行尾空格也算错
- 每题只有 **1 组**官方样例。想要更多数据，用「自定义输入 + 参考解对比」

## 四、样例校正记录（重要，别被误导）

自动抽取的样例不可能 100% 干净。我用 **250 份参考解逐题反跑**核对了一遍：

```
参考解输出 == 原样例     236 题
不一致                   10 题
原样例缺失（略/无）        3 题
参考解本身编译不过         1 题
```

不一致的逐条人工裁决，有争议的再**独立暴力求解**验一遍，结论写在 `题目校正.json` 里，
网站会按它判题并在题面显示说明：

| 题号 | 处理 | 依据 |
|---|---|---|
| S1-020 统计字符 | 保留原样例，判题加编码容错 | 参考解源码是 GBK，输出是 GBK 字节 |
| S1-022 小茗同学很方 | 输入清掉缩进 → `10,3,5` | 题面样例被排版缩进污染 |
| S2-034 三个三位数的关系 | 换成一组合法数据 | 原样例是「就不告诉大家答案了: )」；参考解混进全角分号编不过。答案由独立枚举得 4 组 |
| S2-042 求特殊自然数 | 拆成 3 组用例 | 原题面缺「例子输出」；独立求解 248 = 七进制 503 = 九进制 305 |
| S3-065 / S9-181 重排空格 | 严格比较 + 重算答案 | 题目要求输出长度不变 |
| S5-085 跳水比赛 | 输入空 + 答案 `3 1 5 2 4` | 原样例是占位符；按「每人只对一半」逐条验算 |
| S5-087 比饭量 | 输入空 + 答案 `BCA` | 原样例是「无」；独立枚举得 A>C>B |
| S5-093 侃侃而谈的四位朋友 | 输入空 + 4 行答案 | 原样例是「略」；按五条条件逐条验算 |
| S6-115 集合里的乘法 | 拆成 2 组用例 | 原题面把两组样例连在一起 |
| S6-105 猴子分苹果 | **保留原样例 7** | ⚠️ 参考解有 bug（没检查最后一只猴子是否 ≥1 个），会算成 3 |
| S9-233 井底之蛙 | **保留原样例 3** | ⚠️ 参考解有 bug（整除截断），会算成 2 |
| S7-137 矩阵取数游戏 | **保留原样例 34** | ⚠️ 参考解里带调试输出，会多打印中间表 |

**所以：参考解不是神。** 对比时如果两边不一致，先想想哪边更符合题意。

## 六、改完之后自检

```
python 工具/自检网站.py
```

它会启动一次服务，依次验证：250 题装载 / 找得到 g++ / 读代码 / C++ 和 Python 判题 /
编译失败识别 / 参考解对比 / 严格比较的题 / 代码落盘 / 进度回写 CSV / 无账号接口，
**最后把动过的文件和进度表按开测前的字节原样写回**（md5 一字节不差），全过则打印 `✅ 全部通过`。

`工具\自检环境.py` 是更粗的一遍体检：Python 版本、g++、调试器、250 份模板 / 样例 / 参考答案、
网站文件是否都在。两个都绿，环境就没问题。

## 七、出问题了怎么办

| 现象 | 处理 |
|---|---|
| 页面说「连不上本地服务」 | 服务窗口被关了，重新双击 `启动网站.cmd` |
| 所有题都「编译失败」 | `g++` 不在 PATH 里；跑 `python 工具\自检环境.py` 看第 2 项，启动窗口也会打印编译器路径 |
| Python 题报语法错 | 检查是不是把 C++ 代码写在 Python 标签下（两者分开存） |
| VS Code 里看到的文件没更新 | 网站写盘有延迟，等一秒或点「↻ 重读」 |
| 进度表被写乱了 | `训练网站\备份\` 里取最近一份覆盖回去 |
| 判题结果和 OJ 不一致 | 只有 1 组官方样例，OJ 会用别的数据；用「自定义输入 + 参考解对比」多测几组 |

## 八、环境变量（可选）

| 变量 | 作用 |
|---|---|
| `TS_HOST` | 监听地址，默认 `127.0.0.1`（只给本机）。填 `0.0.0.0` 才会对局域网开放 |
| `TS_PORT` | 起始端口，默认 `8756` |
| `TS_NO_BROWSER` | 设成任意值则启动时不自动开浏览器 |
