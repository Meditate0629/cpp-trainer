# 计算概论 · 训练场

> 一个跑在**你自己电脑上**的刷题网站，仿 LeetCode：250 道题、C++ / Python 双语言判题、
> 和参考解逐行对拍、进度自动记账。**不用注册、不用联网、不用装数据库。**

```
双击 训练网站\启动网站.cmd   →  浏览器自动打开 http://127.0.0.1:8756/
```

---

## 这是什么

| 你得到什么 | 说明 |
|---|---|
| 250 道题 | C++ 入门题，从「变量 + 循环」到「递归 + 结构体」，分 S1~S9 九个阶段 |
| 一份题面 | 每道题都带题面、样例输入输出、参考行数、来源目录 |
| 一套样例 | 250 组官方样例，我逐题用参考解反跑核对过（有争议的 14 处写在校正表里） |
| 250 份参考解 | 卡满 40 分钟再点「参考解」看，看完合上重写一遍 |
| 一个判题网站 | 提交即判分，给出逐行差异；还能拉参考解做**对拍** |
| 一份进度表 | `进度追踪表.csv`，Excel 直接打开，通过自动打勾 |

题面和参考答案来自公开题库
[IntroductionToComputationHomework2022](https://github.com/LC-John/IntroductionToComputationHomework2022)（MIT），
我做了抽取、校正、模板化，以及这个刷题网站。**只用来学 C++，不要拿去做别的事。**

## 三步开始

### 1. 拿到这份代码

```bash
git clone <这个仓库的地址> 题库
```

或者网页右上角 **Code → Download ZIP** 解压（**别解压到路径里带空格或特殊符号的地方**）。

### 2. 装两个东西

| 需要的 | 怎么装 |
|---|---|
| **Python 3.8+** | [python.org](https://www.python.org/downloads/) 下载安装，装的时候**勾上 "Add python.exe to PATH"** |
| **C++ 编译器** | Windows：装 [w64devkit](https://github.com/skeeto/w64devkit/releases)（解压即用，把它的 `bin` 目录加进 PATH）；<br>懒得自己找就用 `python 工具/下载编译器.py` 帮你下（只下载，解压和加 PATH 得自己来）；<br>Linux / macOS：`sudo apt install g++` / `xcode-select --install` |

> 只要 Python 不要 C++ 也能用 —— 那样就只能做 Python 判题，C++ 题会全部报「编译失败」。

### 3. 自检，然后开刷

```bash
python 工具/自检环境.py
```

一行行 `[OK]` 就说明环境齐了。然后：

- **Windows**：双击 `训练网站\启动网站.cmd`
- **Linux / macOS**：`sh 训练网站/start.sh`

浏览器打开 <http://127.0.0.1:8756/>，从 `S1-001 点和正方形的关系` 开始。

> 手机、局域网里的别人**连不上** —— 服务只监听 `127.0.0.1`，就是给你自己用的。

## 怎么用

```
┌──────────┬──────────────────┬────────────────────────┐
│ 题目列表  │ 题面              │ 代码编辑器              │
│ 250 题    │ 题目/输入/输出     │ 语言 ▾ C++ 17 / Python3 │
│ S1~S9    │ 示例 1、示例 2…    │ [运行][提交]            │
│ 搜索/筛选 │ 提示 + 样例说明    │ 测试用例/结果/提交记录   │
└──────────┴──────────────────┴────────────────────────┘
```

| 按钮 / 快捷键 | 作用 |
|---|---|
| `Ctrl+Enter` | 运行 |
| `Ctrl+Shift+Enter` | 提交 |
| 运行 ▶ | 跑「自定义输入」里的数据，**不判分** |
| ☑ 同时跑参考解并对比 | 你的输出 vs 参考解**逐行比对**，等于一个对拍器 |
| 提交 | 按样例判分，全过就写进 `进度追踪表.csv` |
| 参考解 | 看标准答案（没通过会先拦一下，防止手贱） |
| ↻ 重读 / 重置 | 重新从磁盘读 / 恢复空白骨架 |

**代码去哪儿了？** 直接存进 `练习\S1~S9\` 里的 `.cpp`，和 VS Code 打开的是**同一份文件**。
所以：网页里写、VS Code 里写，随便切换。

### 想调试

VS Code 打开 `题库` 文件夹 → 打开某道题的 `.cpp` → 按 `F5`。
`.vscode` 里已经配好编译 / 运行 / 用样例输入跑 / 断点调试（走 PATH 里的 `g++` 和 `gdb`，
不用改任何路径）。

## 我自己加题？

1. 在《进度追踪表.模板.csv》里照样加一行（题号、题目名、阶段、原文件路径）
2. 把题面和参考解分别放进 `练习\` 和 `IntroductionToComputation...\` 对应的位置
3. 跑 `python 工具/生成练习.py` 重建模板和样例

或者更简单：直接在 `练习\` 里新建 `.cpp` 用 `g++` 自己跑，网站只是顺手。

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击 `启动网站.cmd` 一闪就没 | 没装 Python，或者没勾 "Add python.exe to PATH"；先 `python --version` 试试 |
| 网页说「连不上本地服务」 | 服务窗口被关了，重新双击启动 |
| 所有 C++ 题都「编译失败」 | `g++` 不在 PATH 里；跑 `python 工具/自检环境.py` 看第 2 项 |
| Python 题语法错 | 别把 C++ 代码写在 Python 标签下，两种语言分开存 |
| `git pull` 之后进度没了 | 不会 —— `进度追踪表.csv` 已加进 `.gitignore`，只在本地 |
| 判题结果和老师 OJ 不一致 | 每题只有 1 组官方样例，OJ 会用别的数据；用「自定义输入 + 参考解对拍」多造几组 |
