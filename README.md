一个**跑在你自己电脑上**的刷题网站，仿 LeetCode：250 道 C++ 入门题、C++/Python 双语言判题、
和参考解逐行对拍、进度自动记账。

- **不用注册、不用登录** —— 打开就是题目列表
- **不用联网、不用数据库** —— 后端只用 Python 标准库，一个 `server.py` 搞定
- **代码就在硬盘上** —— 网页里写的代码直接落在 `练习/S1~S9/*.cpp`，和 VS Code 打开的是同一份文件
- **只监听 `127.0.0.1`** —— 除了你没人能访问

```bash
git clone https://github.com/Meditate0629/cpp-trainer.git 题库
cd 题库 && python 工具/自检环境.py     # 全绿就说明环境齐了
```

Windows 双击 `训练网站\启动网站.cmd`；Linux / macOS 跑 `sh 训练网站/start.sh`。
浏览器自动打开 <http://127.0.0.1:8756/>。

## 它是什么

| 你得到什么 | 说明 |
|---|---|
| **250 道题** | C++ 入门题，分 S1~S9 九个阶段：变量与分支 → 循环与枚举 → 字符串 → 二维数组 → 函数与递归 → 搜索 → 动态规划 → 综合 → 整卷模拟 |
| **题面** | 每题都带题目描述、输入输出说明、样例、参考行数、原始来源目录 |
| **253 组用例** | 从题面抽取，并用 250 份参考解逐题反跑核对过；有争议的 13 处人工裁决，写在 `训练网站/题目校正.json` |
| **250 份参考解** | 网页里「参考解」按钮读的就是它 —— 建议卡满 40 分钟再看，看完合上重写一遍 |
| **一个判题网站** | 提交即判分并给出逐行差异；还能勾选「同时跑参考解并对比」当**对拍器**用 |
| **一份进度表** | `进度追踪表.csv`，Excel 直接打开；通过自动打勾并记首次通过日期 |

题面和参考答案来自公开题库
[IntroductionToComputationHomework2022](https://github.com/LC-John/IntroductionToComputationHomework2022)（MIT, © 2022 Zhang Huangzhao）。
本仓库做的是抽取、校正、模板化，以及那个判题网站。

## 环境要求

| 必需 | 说明 |
|---|---|
| **Python 3.8+** | 启动网站、跑判题脚本。只用标准库，**不需要 pip install 任何东西** |
| **C++ 编译器** | 判 C++ 题用。`g++` 或 `clang++` 在 `PATH` 里就行 |

可选：`gdb` / `lldb`（VS Code 里断点调试用，不影响判题）。

装编译器：

| 系统 | 怎么装 |
|---|---|
| **Windows** | 下 [w64devkit](https://github.com/skeeto/w64devkit/releases)（解压即用，把它的 `bin` 目录加进 `PATH`）；<br>或者 `python 工具/下载编译器.py` 帮你下载（只下载，解压和加 PATH 要自己做） |
| **Debian / Ubuntu** | `sudo apt install g++` |
| **macOS** | `xcode-select --install`（装的是 clang++，脚本认得） |

> 只有 Python、没有 C++ 编译器也能启动网站，但所有 C++ 题都会报「编译失败」；
> Python 判题不受影响。

## 三步开始

### 1. 拿到代码

```bash
git clone https://github.com/Meditate0629/cpp-trainer.git 题库
```

不想用 git 就点右上角 **Code → Download ZIP** 解压。

> 路径里**尽量别有空格和特殊符号**，中文路径没问题。

### 2. 自检

```bash
cd 题库
python 工具/自检环境.py
```

它会检查 Python 版本、找不找得到 `g++`、**真的编译并跑一个 1+2 的小程序**、题库文件齐不齐
（250 模板 / 250 输入 / 250 输出 / 250 参考解）、网站文件在不在、启动脚本是不是纯 ASCII。
一路 `[OK]` 就说明能用了。

### 3. 开刷

```bash
# Windows
训练网站\启动网站.cmd

# Linux / macOS
sh 训练网站/start.sh
```

浏览器自动打开 <http://127.0.0.1:8756/>，从 `S1-001 点和正方形的关系` 开始。
关掉那个终端窗口就停服务；端口被占用会自动往后找 8757、8758…

首次启动会自动用 `进度追踪表.模板.csv` 生成一份空进度表，所以仓库里不带任何人的进度。

## 界面与快捷键

```
┌──────────┬──────────────────────┬────────────────────────┐
│ 题目列表  │ 题面                  │ 代码编辑器              │
│ 250 题    │ 题目 / 输入 / 输出     │ 语言 ▾ C++ 17 / Python3 │
│ S1~S9    │ 示例 1、示例 2…        │ [运行] [提交]           │
│ 搜索/筛选 │ 提示 + 样例说明        │ 测试用例 / 结果 / 记录   │
└──────────┴──────────────────────┴────────────────────────┘
```

| 按钮 / 快捷键 | 作用 |
|---|---|
| `Ctrl+Enter` | 运行（不判分） |
| `Ctrl+Shift+Enter` | 提交（判分） |
| 运行 ▶ | 跑「自定义输入」里的数据，看输出对不对 |
| ☑ 同时跑参考解并对比 | 你的输出 vs 参考解**逐行比对**，等于一个对拍器 |
| 提交 | 按官方用例判分，全过就写进 `进度追踪表.csv` |
| 参考解 | 看标准答案（没通过的会先拦一下，防止手贱） |
| ↻ 重读 / 重置 | 重新从磁盘读 / 恢复空白骨架 |

代码在停止输入 0.9 秒后自动保存到 `练习/`，所以随时可以切到 VS Code 接着写。

## 用 VS Code 写 / 调试

网页编辑器没有补全、没有调试。要这些就用 VS Code 打开**题库根目录**（不是单个文件）：

| 操作 | 快捷键 / 方法 |
|---|---|
| 编译当前文件 | `Ctrl+Shift+B` |
| 编译并运行 | `Ctrl+Shift+P` → `Tasks: Run Task` → `run` |
| 用官方样例跑一遍 | `Ctrl+Shift+P` → `Tasks: Run Task` → `run with sample` |
| **断点调试** | 打开 `.cpp` 按 `F5` |

`.vscode/` 里已经配好了，`g++` / `gdb` 走 `PATH`，换机器不用改任何路径。
改完回网页点「↻ 重读」再「提交」。

## 判题规则

| 语言 | 命令 | 时限 |
|---|---|---|
| C++ 17 | `g++ -std=c++17 -O2 -Wall -Wl,--stack=16777216` | 编译 60 s，运行 5 s |
| Python 3 | `python -X utf8 main.py` | 运行 5 s |

- 栈加到 16 MB，不然 S6 的深递归题会莫名崩
- 比对忽略行尾空格、末尾空行、CRLF
  **例外**：`重排空格`（S3-065 / S9-181）要求输出长度与原串相同，行尾空格也算错
- 每题只有 1 组官方用例（少数 2~3 组）。想要更多数据，用「自定义输入 + 参考解对拍」

## 已知的坑

**3 道题的参考解本身有 bug**，判题以官方用例为准：

| 题号 | 参考解的问题 |
|---|---|
| S6-105 猴子分苹果 | 没检查最后一只猴子是否 ≥ 1 个，会算成 3（正确是 7） |
| S9-233 井底之蛙 | 整除截断，会算成 2（正确是 3） |
| S7-137 矩阵取数游戏 | 代码里带调试输出，会多打印中间表 |

**13 处样例做过人工校正**（`训练网站/题目校正.json`，逐条附了依据）：
S1-020、S1-022、S2-034、S2-042、S3-065、S5-085、S5-087、S5-093、S6-105、S6-115、S7-137、S9-181、S9-233。
其中 S2-034 / S2-042 / S5-085 / S5-087 / S5-093 的原题面根本没给答案，是独立暴力求解验出来的。

细节见 [`训练网站/README.md`](训练网站/README.md) 第四节。

## 自己加题

1. 在 `进度追踪表.模板.csv` 里照样加一行（题号、题目名、阶段、原文件路径）
2. 把题面和参考解放进 `练习/` 和 `IntroductionToComputationHomework2022-master/` 对应位置
3. 跑 `python 工具/生成练习.py` 重建模板和样例

或者更省事：直接在 `练习/` 里新建 `.cpp`，用 `g++` 自己跑，网站只是顺手。

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击 `启动网站.cmd` 一闪就没 | 没装 Python，或装的时候没勾 "Add python.exe to PATH"。命令行里先试 `python --version` |
| 网页说「连不上本地服务」 | 服务窗口被关了，重新启动一次 |
| 所有 C++ 题都「编译失败」 | `g++` 不在 `PATH` 里。跑 `python 工具/自检环境.py` 看第 2 项 |
| Python 题语法错 | 别把 C++ 代码写在 Python 标签下，两种语言分开存 |
| `git pull` 之后进度没了 | 不会。`进度追踪表.csv` 在 `.gitignore` 里，只存在你本地 |
| 判题结果和老师 OJ 不一致 | 每题只有 1 组官方用例，OJ 用的是别的数据。用「自定义输入 + 参考解对拍」多造几组 |
| 想发给同学用 | 这个版本只监听 `127.0.0.1`，就是设计成单人用的 |
